# Neural Network / MLP

Phase 2 step 9. `MlpSimulation` implements a small one-hidden-layer dense network from scratch. Hidden weights use `ManualMatrix`; inputs, biases, activations, and output weights use `ManualVector`. The forward pass explicitly computes every hidden weighted sum/activation and then the output neuron.

The module is intentionally small enough that every connection and intermediate value can be visualized and inspected.
