# Decision Tree Core

Phase 1 step 8 implements a binary classification Decision Tree from scratch.

- Training examples are stored as project-owned `ManualVector` feature vectors.
- Labels are binary (`0` / `1`) for the teaching module.
- Candidate thresholds are generated by explicit insertion-sort over example indexes for each feature.
- Every candidate partitions the current node's example indexes into left/right arrays and scores impurity reduction.
- Gini is the default criterion; entropy is a real alternative criterion.
- Tree nodes store example indexes, class counts, impurity, split feature/threshold/gain, child IDs, and leaf prediction.
- Pure nodes, maximum depth, too-small nodes, or no useful gain stop as leaves.
- Prediction follows one root-to-leaf path in `O(depth)`.

The implementation does not call a framework sorting routine, tree builder, statistics package, or ML library.
