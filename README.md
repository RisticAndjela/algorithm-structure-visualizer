# Algorithm Visualizer — Phase 1

A Blazor WebAssembly architectural skeleton for visual simulations of data structures and algorithms.

- Target: .NET 8 (`net8.0`), with a straightforward upgrade path to .NET 9 by updating `TargetFramework` and the Blazor package versions.
- Frontend: Blazor WebAssembly, Razor components, and CSS isolation.
- Visualization: SVG is planned as the default renderer so the application can remain C#-first without a traditional JavaScript/TypeScript frontend.
- Phase 1 intentionally does not implement the algorithms.

See `ARCHITECTURE.md` for the project layout and state-management approach.
